
# Frontend

- React
- TypeScript

## Требования

- Node.js
- npm

## Локальный запуск

1. Клонировать репозиторий:
 ```python
   git clone https://github.com/victoriapetrova2910/Project_custombus.git
 ```
2. Перейти в папку frontend:
```python
   cd Project_custombus/frontend
```
3. Установить зависимости:
```python
   npm install
```

5. Запустить приложение:
```python
   npm run dev
```
6. Открыть адрес, указанный Vite в терминале.
   По умолчанию:
```python
   http://localhost:5173/
```
## Сборка

Проверка TypeScript и сборка приложения:
```python
   npm run build
```
Проверка качества кода:
```python
   npm run lint
```
Собранные файлы размещаются в папке dist/.

## Режимы поездки

### Поехать сейчас

> Пользователь выбирает остановки отправления и назначения, указывает количество пассажиров и запускает поиск.
> В дальнейшем система должна находить подходящий транспорт и показывать предложение поездки.

### Запланировать

> Пользователь дополнительно выбирает дату и время поездки.
> Предварительный заказ допускается в интервале от 30 минут до 48 часов вперёд, с шагом времени 10 минут.
> Это правило реализовано во frontend и должно быть
согласовано с backend.

## Текущая реализация

Реализованы:

- Главная страница.
- Форма выбора параметров поездки.
- Переключение режимов заказа.
- Проверка пользовательского ввода.
- Интерактивная карта.
- Страница результатов поиска.
- Демонстрационные состояния поиска:
  - загрузка;
  - транспорт найден;
  - транспорт не найден;
  - ошибка.
- Базовая мобильная адаптация.
- Подготовленный модуль API.

## Ограничения текущей версии

- В режиме «Поехать сейчас» поиск и параметры поездки демонстрационные.
- В режиме «Запланировать» остановки, время, цена и доступность мест загружаются из backend.
- Для найденных через API рейсов оформление пока недоступно.
- Бронирование, оплата, личный кабинет и QR-билеты работают в демо-режиме с данными в браузере.
- Диспетчерская панель показывает демонстрационные показатели.
- На карте цветом выделены справочные границы НАО, ТАО и Сколково. Зелёные точки показывают активные остановки «По пути».
- Кнопка «Показать рейс на карте» рисует схему участка между выбранными остановками. Линия проходит через остановки по порядку, геометрия проезда по дорогам в API отсутствует.

## Подключение backend

Frontend предполагает взаимодействие с backend на FastAPI.

В `src/api/trips.ts` подготовлена функция поиска запланированных поездок.

Базовый URL можно передать через переменную окружения:

```python 
   VITE_API_BASE_URL=http://127.0.0.1:8000
```
Для запланированных поездок backend предоставляет `POST /api/v1/preorders/search`.
Этот запрос используется в режиме «Запланировать». Для проверки нужны миграции, импорт остановок и рейсы в PostgreSQL.

Для локальной настройки можно использовать файл
frontend/.env.local. Его не следует коммитить.
