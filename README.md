# Project_custombus

* от точки А до точки В
* **подбор свободного автобуса**
* попутные пассажиры (кто едет в ту же стороны, что и человек)

* **формирование гарантированного потока пассажиров**
* оптимизация маршрута (прокладывание маршрута)
* гарантия, что поездка ТОЧНО будет
* планирование загрузки автобуса
