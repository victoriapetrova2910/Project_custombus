# Project_custombus

## О проекте
Сервис заказных перевозок «По пути» (Мосгортранс) — это гибрид маршрутки и такси в Новой Москве. Пассажир указывает точки А и Б, а алгоритм строит динамический маршрут, подсаживая попутчиков. 

**Основная проблема:** сервис заказных перевозок «По пути» строит маршруты только в реальном времени — система на ходу подбирает автобус и добавляет попутные заезды. Из-за этого время в пути становится непредсказуемым, а в часы пик количество свободных машин сокращается. Механизма предзаказа при этом нет, поэтому пассажир не может спланировать поездку заранее, а перевозчик не может рассчитывать на гарантированную загрузку.

**Наша задача:** понять, что нужно сделать для того, чтобы пассажиры смогли пользоваться *услугой предварительного заказа*, перевозчик — обслуживать *гарантированный объём пассажиропотока*

---

## Цели и задачи

### Для пассажира:
- Предзаказ поездки за несколько часов.
- Гарантированное место и понятное время поездки.
- Прозрачные правила оплаты, отмены и возврата.
- Предсказуемый маршрут и время в пути.

### Для перевозчика:
- Прогнозируемый спрос и загрузка транспорта.
- Учитывание предзаказов при планировании рейсов.
- Снижение недозагруженных и холостых пробегов.
- Эффективное объединение заказов.

### Для сервиса:
- Определить пользовательский сценарий предзаказа.
- Разработать правила бронирования, оплаты и отмены.
- Определить принципы формирования рейсов.
- Определить показатели эффективности предзаказа.
