# Project_custombus: контракты и алгоритмы

## Структура

```python
zadanie2_personal/
├── docs/
│   ├── openapi.yaml        # контракт API (OpenAPI 3.0)
│   └── contracts.md        # контракты в читаемом виде: API и модули
├── algorithm/
│   ├── grouping.py         # группировка предзаказов в рейсы
│   ├── scheduling.py       # распределение автобусов по рейсам
│   └── refund.py           # правила возврата при отмене
├── tests/
│   ├── test_algorithm.py   # тесты группировки и распределения

```

## docs/

### openapi.yaml
Описание всех эндпоинтов backend, написано по фактическому коду.
- Префикс: `/api/v1`.
- Статусы заказа: `pending`, `confirmed`, `cancelled`.
- Статусы платежа: `pending`, `paid`, `failed`.
- Эндпоинты, которых ещё нет в коде, помечены `x-status: planned`.

Открыть: Swagger Editor (editor.swagger.io), вставить содержимое файла.

### contracts.md
Тот же контракт в читаемом виде:
- **Документация API:** метод и адрес, параметры таблицей, пример запроса и ответа, таблица ошибок.
- **Документация модулей:** сигнатура функции, параметры, что возвращается, исключения.

## algorithm/

### grouping.py
Группировка предзаказов в рейсы, жадный алгоритм.
- `build_trips_greedy(preorders, p, capacity)` — основная функция.
- `is_compatible(trip, order, p, capacity)` — проверка, можно ли добавить заказ в рейс.
- Классы: `Stop`, `Preorder`, `Params`, `Trip`.

Условия совместимости: вместимость, время посадки (15 мин), близость остановок (500 м), направление (45°), удлинение поездки (1.5).

### scheduling.py
Распределение автобусов методом best fit.
- `assign_vehicles(trips, vehicles, trip_duration, buffer)` — возвращает `{trip_id: vehicle_id или None}`.
- Класс: `Vehicle`.

Один автобус не назначается на пересекающиеся рейсы. Между рейсами одного автобуса буфер 15 мин.

### refund.py
Правила возврата при отмене.
- `refund_ratio(...)` — доля возврата: 1.00, 0.50 или 0.
- `refund_amount(...)` — сумма возврата, округлённая до копеек.
- Класс: `RefundPolicy`.

| Когда отменили | Возврат |
|---|---|
| до 10 мин после оплаты | 100% |
| больше чем за 2 ч до отправления | 50% |
| от 30 мин до 2 ч до отправления | 50% (предположение) |
| меньше 30 мин до отправления или после | 0% |

## tests/

- `test_algorithm.py` — 9 тестов: группировка, вместимость, время, направление, удалённые остановки, детерминированность, выбор автобуса, пересечения.
- `test_refund.py` — 6 тестов: все зоны возврата и округление.

Запуск из корня папки:

```
PYTHONPATH=. python3 -m unittest discover -s tests -p "test_*.py" -v
```

Нужен Python 3.10+, сторонние библиотеки не нужны. Ожидаемый результат: `Ran 15 tests ... OK`.

## Предположения, которые нужно согласовать

- Что считать мгновенной отменой (сейчас 10 минут).
- Возврат при отмене от 30 минут до 2 часов до отправления (сейчас 50%).
- Пороги группировки: окно посадки, радиус остановок, угол направления, коэффициент удлинения.
- Сумма оплаты в `/pay` захардкожена (500), по интервью 75–200 руб.
